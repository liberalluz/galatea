# Galatea

简体中文 · [English](README.md)

> 学美式英语的音标：KK，配 DJ 与 IPA 视图、发音音频和手写练习。
> Flutter Web 首发。

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

## 状态

**v0.1.0 已发布。** 图表、详情、练习与复习四条流已在 Web 构建端到端跑通；GitHub Pages 部署随后跟进。

## 它是什么

- **一张表，三套记号。** KK 是默认；DJ 和 IPA 一步切换，不是分开的页面。
- **每个符号都有音和形。** 每个符号配发音音频，书写练习由笔顺数据引导。
- **错题会回来。** 答错的条目重新进入间隔重复复习队列。
