# SDD — galatea v0.1.0

简体中文 · [English](SDD.md)

## 1. 范围与来源

- 需求：`docs/specs/controlled/SRS.md`（`REQ-001`–`REQ-030`，P1 切片 v0.1.0；
  `REQ-025` 属 v0.2.0，仅作追溯）。
- 行为与布局：`galatea-docs/design/design-spec.md`——只引用不复制。其中标为
  **固定** 的项在此不再自行发明。
- 交互路径：`galatea-docs/design/ux-flows.md`（每个 R id 一节，含失败/空态与
  质量约束小节）。
- 线框：`galatea-docs/design/prototypes.md`（P0–P8）。
- 有长期成本的决策：`docs/decisions/ADR-0001`–`ADR-0004`。

## 2. 架构总览

单一 Flutter 代码库，Web 首发（v0.1.0），iOS 在 v0.2.0。三层：

- **内容层**——随包分发的版本化数据文件（音位、体系映射、例词、字形/笔顺）
  加音频缓存；无后端（ADR-0004）。
- **领域层**——音位目录（ADR-0001）、练习会话状态、实现 PRD 产品规则的
  星级/复习引擎、设置。
- **UI 层**——三 Tab 外壳加下钻页；全部行为与降级态遵循 design-spec
  Components 与 ux-flows 失败分支。

依赖单向：`UI → 领域 → 内容`；领域层不读 UI 状态，内容层不引入领域类型。

## 3. 设计分节

### §3.1 应用外壳与导航

- 底部三 Tab（`tab-chart` / `tab-practice` / `tab-me`，文案「音标 / 练习 /
  我」）常驻，顺序与文案固定（design-spec Components），默认落在
  `tab-chart`；各 Tab 保留自己的滚动位置。详情、设置与
  关于为下钻页，顶部返回；下钻页不显示底部 Tab，返回后回原滚动位置。
- 首启轻提示（`S1`，P6）：仅首次启动，点按任意处或 `first-run-dismiss`
  按钮（「知道了」）关闭，不阻塞
  底层页面。
- 待复习状态条（`S2`，P1/P5）：音标页网格上方；N = 0 或不可用时整行隐藏；
  点击深链到练习 Tab 的复习模式。
- Web 构建覆盖本切片全部需求（`REQ-024`）；iOS（`REQ-025`，v0.2.0）原样
  复用本设计（design-spec 范围）。

### §3.2 音标页

- 5 列印刷体网格、按语音类别分组，末行左对齐、不跨组拼行；窄屏横向滚动或
  缩放，50 个音位全可达（`REQ-001`、`REQ-002`，线框 P1）。
- 体系切换 KK/DJ/IPA 在顶部，默认 KK，切换保持当前音位，缺字形时保留原体系
  （`REQ-003`，ADR-0001）。
- 默认态：点击进详情页（`REQ-004`）；直读态：右上角开关，点击只发音，固定
  提示行（copy `reading-mode-hint`）位于开关行与网格之间（`REQ-005`，线框
  P2）。
- 待复习状态条见 §3.1（`S2`）。

### §3.3 详情页

固定四区顺序：顶部横向音标切换栏 → 发音 → 口型 → 书写（范本 + 笔顺）→
2×2 例词卡片（`REQ-006`–`REQ-011`，线框 P3）。

- 发音按钮带 loading/ready/playing/failed 状态；失败重试一次，不阻断其他区；
  音频管线见 ADR-0002。
- 每音位一张口型图；缺图用同尺寸占位，不串用他人图。
- 临摹区（touch，笔迹即时跟随，中断保留已画笔画）与笔顺播放控件（缺笔顺
  数据时禁用并显示固定 `stroke-pending` 文案）——字形数据见 ADR-0003。
- 2×2 例词卡片：图片 + 词句，无译文；缺图用占位，卡片不隐藏（`REQ-010`、
  `REQ-014`）。
- 横向切换栏到相邻音位，各区随之刷新，首尾不回绕（`REQ-011`）。

### §3.4 练习

- 选范围：类别标签 + 5 列多选网格 + 确定；未选时确定禁用；筛选无结果显示
  固定空态（`REQ-015`，线框 P4）。
- 题型形态固定：认读（印刷体题干，4 选项 1 正确）、听辨（发音题干，2 选项，
  高亮后确定，音频失败可跳过）、书写（手写范本，书写区，✓/× 判定，空提交
  提示 `trace-first`）、连线（发音连另一套体系符号，配对成功变灰，连错回弹）
  ——`REQ-016`–`REQ-019`。书写判定宽松度在设计评审定死（SRS 待定项）。
- 进度条与范围标签常驻顶部；分母为所选范围；分母 0 时隐藏进度条；任一缺数据
  区域独立降级，不整页失败（`REQ-020`）。
- 每次作答后即时反馈；完成判定 = 范围内答题 ≥ 1 次，与对错无关（`REQ-021`，
  PRD 产品规则）。

### §3.5 复习与掌握度

- 复习是练习 Tab 内的模式切换，不占 Tab；到期音位按星级下降规则与
  1/2/4/7/15 天间隔进入；答错重置到第 1 档；空队列显示 `review-empty`
  （`REQ-022`，线框 P5）。
- 每个音位带三体系共享的 0–3 星（ADR-0001）；星级严格按 PRD 产品规则升降。
  掌握度统计收进我 Tab，可按体系过滤，分母恒为 50（`REQ-023`）。

### §3.6 内容数据模型

- 单一音位实体，附每体系显示字段、例词、字形与笔顺记录（ADR-0001）。音标表
  与题干用印刷体；临摹与书写任务用手写体（`REQ-013`）。
- 数据文件随包分发、版本化、独立于应用代码；来源标注（copy `source-note`）
  标明单一来源（`REQ-001`、`REQ-012`，ADR-0004）。备选：若分册数据无法授权，
  按公开 KK/DJ/IPA 对照表自建并如实标注（SRS 依赖备选表）。

### §3.7 音频管线

- 首次请求时 TTS 生成并缓存到设备；之后播放读缓存；离线且无缓存显示固定
  「需联网」态，不阻断练习（`REQ-006`、`REQ-029`，ADR-0002）。

### §3.8 本地持久化与设置

- 本地存储星级、复习计划、完成计数与设置；仅存本设备，已在关于页披露
  （`about-limitation`）（`REQ-021`–`REQ-023`，ADR-0004）。
- 设置收进我 → 设置：语言（zh-CN / en-US，即时生效于全部文案）与音频开关
  （影响发音按钮与听辨题）（`S3`，线框 P7）。
- 关于页（`S4`，线框 P8）承载版本、来源标注、开源说明、反馈入口与仅存本
  设备的限制披露。

### §3.9 质量约束（REQ-027–REQ-030）

- **字体（`REQ-027`）**：回退字体链覆盖 IPA 专属符号（ʃ θ ŋ ɚ 等）；缺字
  渲染固定占位框 + design-spec R27 的固定缺字文案（字面文案，暂无 Copy
  key），绝不用豆腐块。
- **小屏（`REQ-028`）**：5 列网格横向滚动或缩放，不裁切、不折列，50 个音位
  全可达；所有可点区域 ≥ 44 pt。
- **离线（`REQ-029`）**：音位数据、体系映射与词句文本自安装起本地可用；音频
  按 ADR-0002；练习流程无硬性网络依赖。
- **无障碍（`REQ-030`）**：符号带 aria-label / 朗读文本（缺标记回退音位
  id），按钮键盘可达、焦点可见，状态不单靠颜色表意（WCAG AA 对比度）。Tab
  顺序按 design-spec Accessibility。

### §3.10 双语交付

- 仓语言 en-US：SDD/ADR 等受控文档遵循仓语言规则；文档仓产品文档保持其翻译
  成对（`REQ-026`）。
- 应用内文案：zh-CN 为源、en-US 为翻译，使用 design-spec 的固定 Copy 表
  （30 个 key；标 A15 待产品负责人确认的 key 照常接线，措辞可能调整）。UI
  语言切换即时生效。

## 5. 决策

- `ADR-0001`——单一音位实体，体系作为显示映射。
- `ADR-0002`——音频用 TTS 加设备端缓存。
- `ADR-0003`——手写字形与笔顺为自制矢量数据。
- `ADR-0004`——内容随包分发、状态仅存本设备、无后端。
