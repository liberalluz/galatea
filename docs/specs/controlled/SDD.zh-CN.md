# SDD — galatea v0.2.0

简体中文 · [English](SDD.md)

## 1. 范围与来源

- 需求：`docs/specs/controlled/SRS.md`（`REQ-001`–`REQ-036`；`REQ-031`–
  `REQ-035` 复述产品负责人 2026-11-21 确认的 v0.2.0 交互改版；`REQ-036`
  复述 2026-11-23 确认的单屏详情页；`REQ-025` 属 v0.2.x 补丁，仅作追溯）。
- 行为与布局：`galatea-docs/design/design-spec.md`——只引用不复制。其中标为
  **固定** 的项在此不再自行发明。
- 交互路径：`galatea-docs/design/ux-flows.md`（每个 R id 一节，含失败/空态与
  质量约束小节）。
- 线框：`galatea-docs/design/prototypes.md`（P0–P8）。
- 有长期成本的决策：`docs/decisions/ADR-0001`–`ADR-0004`。

## 2. 架构总览

单一 Flutter 代码库，Web 首发（v0.1.0），iOS 在 v0.2.x 补丁。三层：

- **内容层**——随包分发的版本化数据文件（音位、体系映射、例词、字形/笔顺）
  加预留媒体路径；无后端（ADR-0004）。
- **领域层**——音位目录（ADR-0001）、练习会话状态、实现 PRD 产品规则的
  星级/复习引擎、设置。
- **UI 层**——双 Tab 外壳加下钻页；全部行为与降级态遵循 design-spec
  Components 与 ux-flows 失败分支。

依赖单向：`UI → 领域 → 内容`；领域层不读 UI 状态，内容层不引入领域类型。

## 3. 设计分节

### §3.1 应用外壳与导航

- 底部双 Tab（`tab-chart` / `tab-me`，文案「音标 / 我」）常驻，顺序与文案
  固定（design-spec Components），默认落在 `tab-chart`；各 Tab 保留自己的
  滚动位置（`REQ-031`）。详情、题目、复习、设置与关于为下钻页，顶部返回；
  下钻页不显示底部 Tab，返回后回原滚动位置。
- 首启轻提示（`REQ-033`，骨架 S1，P6）：仅首次启动，点按任意处或
  `first-run-dismiss` 按钮关闭，不阻塞底层页面。
- 待复习状态条（`REQ-022`，决策 8，P1/P5）：音标页网格上方 + 我页掌握度
  卡片底部；N = 0 或不可用时隐藏；点击深链到我 Tab 复习入口——练习 Tab
  已不存在。
- Web 构建覆盖本切片全部需求（`REQ-024`）；iOS（`REQ-025`，v0.2.x 补丁）原样
  复用本设计（design-spec 范围）。

### §3.2 音标页

- **共享行模型**——一份行定义同时服务音标网格、选行练习态与详情圆圈：粗组
  （元音 / 辅音）内按发音部位顺序切行，每行 5 个槽位、末行按实际数；数据层
  直接暴露行划分，三个界面共用同一分组而不各自推导（`REQ-002`、`REQ-011`、
  `REQ-015`；PD 行定义 A）。
- 5 列印刷体网格，只渲染「元音 / 辅音」两个粗组头、细分标签不显示，末行左
  对齐、不跨组拼行；窄屏横向滚动或缩放，48 个音位全可达（`REQ-002`，线框
  P1）。总表不带来源页脚；拆分后的来源标注在关于页（`REQ-001`，决策 7）。
- 体系切换 KK/DJ/IPA 在顶部，默认 KK，切换保持当前音位，缺字形时保留原体系
  （`REQ-003`，ADR-0001）。所选体系存于外壳持有的控制器（`NotationController`），
  详情页读到的是用户在音标页选中的同一体系（`REQ-036`）。
- 默认态：点击进详情页（`REQ-004`）；直读态：右上角开关，点击只发音，固定
  提示行（copy `reading-mode-hint`）位于开关行与网格之间（`REQ-005`，线框
  P2）。
- 练习入口（`REQ-015`，决策 3，P1）：右下浮动按钮（常态深色）进入本页选行
  态——顶栏变为固定 `请选择` 栏，带已选行数与取消；默认选中第一行（整行
  高亮），点其他行移动单行选中——一次仅一行；确定后按所选行开练。浮动按钮
  与选行态不受直读开关影响。不存在独立选范围屏。

### §3.3 详情页

详情页是一条扁平内容流（`REQ-036`，B32 裁定，线框 P3 重画）：页面主体为
单列居中、限宽 420–480 px，无断点分支；各分区去掉卡片外壳与分区标题；
固定部分占住列的上方，2×2 例词区吃掉它们留下的高度并铺到屏幕底边。

顺序：顶栏（同行成员圆圈 + 印刷体符号）→ 映射行 → 口型小卡与书写卡并排 →
发音内联行 → 2×2 例词卡片（`REQ-006`–`REQ-011`、`REQ-036`）。

- 同行成员圆圈（`REQ-011`，决策 5）：圆圈位于顶栏内并摊开占满栏宽，按共享
  行模型逐个渲染当前音位所在行的成员（5 个圆圈，末行按实际数），默认选中
  被点音位而非行首；相邻 = 同行成员，切换不跨行，行首尾不回绕。页面体内不再
  有第二处切换栏。
- 映射行（`REQ-036`）：顶栏与书写区之间的一行，把该音的拼写片段与当前所选
  体系的印刷体符号配对——左 chip 取自音位目录的 `letters` 字段，右值为所选
  体系的印刷体符号。页面不再重复大字形，也不显示星级行；掌握度星级保留在
  「我」Tab 统计（`REQ-023`）。
- 每音位一个口型槽位（`REQ-007`）：槽位渲染为书写卡旁的小卡，书写卡是页面
  主视觉并带十字辅助线；授权素材缺失时以固定占位交付，数据结构预留图片路径；
  占位不串用他人图、不留空白区。
- 唯一书写格（`REQ-008`、`REQ-009`，ADR-0003）：进页自动播一次笔顺；点该格
  重播笔顺并联动发音（决策 13）；缺笔顺数据保持固定 `stroke-pending` 态并
  禁用播放，与临摹相互独立。手写范本以等比映射居中画入书写卡，字形保持自身
  比例，四周留白。
- 手写画板弹层（`REQ-035`，决策 12）：内容层右上角的圆形手写控件打开自由
  临摹画板，以弹层覆盖详情页——灰底范本、十字虚线、笔迹跟随、清除重写、
  完成/关闭回详情页。顶栏不带手写控件。它是弹层不是路由，不产生分数或判定；
  判分仅属书写题（`REQ-018`）。
- 发音行（`REQ-006`）：书写卡正下方一行内联，带印刷体符号与喇叭按钮，四态
  固定为 loading / ready / playing / failed；失败重试一次，不阻断其他分区。
- 2×2 例词卡片（`REQ-010`，决策 10）：例词区吃掉固定部分留下的高度并铺到
  底边；每卡 1 图，并按音位级展示形态取 1 例词或 1 例句——两者绝不同时出现；
  无译文；缺图用占位，卡片不隐藏（`REQ-014`）。

### §3.4 练习

- 入口与范围（`REQ-015`、`REQ-034`）：题目页自音标页选行确定（新练，按所选
  单行）或复习入口（到期队列）进入——两路渲染同一共用题目页，仅选题来源
  不同；按源选题是领域层职责，不做页面变体。
- 进度条与批次标签常驻顶部（`REQ-020`，决策 4）：右上角标签显示元音 / 辅音，
  与所选行粗组一致；复习会话显示其来源对应的标签。
- 题型形态固定：认读（印刷体题干，4 选项 1 正确）、听辨（发音题干，2 选项，
  高亮后确定，音频失败可跳过）、书写（手写范本，书写区，✓/× 判定，空提交
  提示 `trace-first`）、连线（发音连另一套体系符号，配对成功变灰，连错回弹）
  ——`REQ-016`–`REQ-019`。书写判定宽松度在设计评审定死（SRS 待定项）。
- 每次作答后即时反馈；完成判定 = 答题 ≥ 1 次，完成率分母为所选行音位数
  （`REQ-021`，PRD 产品规则）；分母 0 时隐藏进度条；任一缺数据区域独立降级，
  不整页失败。

### §3.5 复习与掌握度

- 复习入口在我页掌握度卡片下钻（`REQ-022`，决策 8，P5）；复习状态条深链到
  该入口（见 §3.1）。到期音位按星级下降规则与 1/2/4/7/15 天间隔进入；答错
  重置到第 1 档；空队列显示 `review-empty`；复习会话走共用题目页
  （`REQ-034`）。
- 每个音位带三体系共享的 0–3 星（ADR-0001）；星级严格按 PRD 产品规则升降。
  掌握度统计收进我页首页，可按体系过滤，分母恒为 48（`REQ-023`）。

### §3.6 内容数据模型

- 单一音位实体，附每体系显示字段、例词、字形与笔顺记录（ADR-0001）。音标表
  与题干用印刷体；临摹与书写任务用手写体（`REQ-013`）。例词记录预留 image
  字段、口型记录预留图片路径，占位交付后续替换不改结构（`REQ-007`、
  `REQ-014`）。
- 音位记录带 `letters` 字段——每音位一条代表性拼写片段——由详情页映射行的
  左 chip 渲染（`REQ-036`）。例词记录带音位级 `displayForm`，决定其卡片显示
  例词还是例句；两者绝不同时出现（`REQ-010`）。
- 字形记录携带基础笔画与按体系的变体列表。KK / DJ / IPA 字形同形的 32 个
  音位共用一套骨架；4 条纯长音（`i`、`ɑ`、`ɔ`、`u`）在 DJ 与 IPA 下补一笔
  长音；12 条字形本身不同的（`e`→`eɪ`、`ɛ`→`e`、`o`→`əʊ`、`ɝ`→`ɜː`、
  `ɚ`→`ə`、`ɪr`→`ɪə`、`ɛr`→`eə`、`iə`→`ɪə`、`ɑr`→`ɑː`、`ɔr`→`ɔː`、
  `ʊr`→`ʊə`、`g`→`ɡ`）随所选体系换骨架（`REQ-012`、`REQ-013`）。书写区在
  该体系无变体时读取基础笔画。
- 数据文件随包分发、版本化、独立于应用代码；来源标注拆分为固定文案——设计
  规格的 `source-note`（KK：书名 + ISBN 9787119061207）与 `about-notation-note`
  （DJ / IPA 为国际通用音标符号，不来自该教材）——只在关于页渲染，渲染时不从
  数据拼装任何内容（`REQ-001`、`REQ-012`，决策 7，ADR-0004）。对照数据的
  source 块携带 KK 分册书名与 ISBN，不带公开对照表的引用列表。

### §3.7 音频管线

- 音频由端侧实时合成（Web Speech）提供，无缓存（`REQ-006`、`REQ-029`）；
  2026-11-21 产品裁定取代 ADR-0002 的缓存设计，ADR 保留为历史记录。合成
  失败显示固定「需联网」态，不阻断练习。

### §3.8 我页与设置

- 我 Tab 宿主四页（`REQ-032`，决策 8）：首页（掌握度统计卡片、待复习状态条、
  复习/设置/关于入口）、复习下钻（§3.5）、设置与关于。
- 设置收进我 → 设置：语言（zh-CN / en-US，即时生效于全部文案）与音频开关
  （影响发音按钮与听辨题）（`S3`，线框 P7）。
- 关于页（`S4`，线框 P8，B 方案）是三组分区叠在固定 62px 标签列上，每组标题压
  在自己的行之上：应用信息放版本，数据来源放 `KK` 行（分册书名 + ISBN
  9787119061207）与 `DJ / IPA` 行（国际通用音标符号、不来自该教材），使用与反馈
  放开源说明、反馈双入口与仅存本设备的限制披露（`REQ-001`、`REQ-012`）。体系名入
  标签列、值列只放内容，渲染时不从对照数据拼装任何内容。间距、标签列与字阶取自
  设计规格的 token（`AppTokens`），不由逐屏数字写死；邮箱地址未配置时该入口为
  disabled 灰态，项目仓库入口打开
  `https://github.com/liberalluz/galatea/issues`。

### §3.9 质量约束（REQ-027–REQ-030）

- **字体（`REQ-027`）**：回退字体链覆盖 IPA 专属符号（ʃ θ ŋ ɚ 等）；缺字
  渲染固定占位框 + design-spec R27 的固定缺字文案（字面文案，暂无 Copy
  key），绝不用豆腐块。
- **小屏（`REQ-028`）**：5 列网格横向滚动或缩放，不裁切、不折列，48 个音位
  全可达；所有可点区域 ≥ 44 pt。
- **离线（`REQ-029`）**：音位数据、体系映射与词句文本自安装起本地可用；音频
  由端侧合成提供、无缓存文件（§3.7）；练习流程无硬性网络依赖。
- **无障碍（`REQ-030`）**：符号带 aria-label / 朗读文本（缺标记回退音位
  id），按钮键盘可达、焦点可见，状态不单靠颜色表意（WCAG AA 对比度）。Tab
  顺序按 design-spec Accessibility。

### §3.10 双语交付

- 仓语言 en-US：SDD/ADR 等受控文档遵循仓语言规则；文档仓产品文档保持其翻译
  成对（`REQ-026`）。
- 应用内文案：zh-CN 为源、en-US 为翻译，使用 design-spec 的固定 Copy 表
  （30 个 key；标 A15 待产品负责人确认的 key 照常接线，措辞可能调整）。UI
  语言切换即时生效。

## 5. 决策

- `ADR-0001`——单一音位实体，体系作为显示映射。
- `ADR-0002`——音频用 TTS 加设备端缓存；其缓存口径被 2026-11-21 产品裁定
  取代（§3.7，`REQ-029`）。
- `ADR-0003`——手写字形与笔顺为自制矢量数据。
- `ADR-0004`——内容随包分发、状态仅存本设备、无后端。
