# STP — galatea v0.1.0（中文译文）

[English](STP.md) · 简体中文

## 范围

对 `docs/specs/controlled/SRS.md`（`REQ-001`–`REQ-030`）做验证，依据
`docs/specs/controlled/SDD.md` 的设计。被测平台为 Flutter Web 构建
（`REQ-024`）；`REQ-025`（iOS）属 v0.2.0，记为 TBD。

工具集：

- `flutter test`：widget 与单元层用例；
- 浏览器检查（DevTools 证据）：质量约束（`REQ-027`–`REQ-030`）与平台行为；
- `check_language.py` 与 `check_verification.py`：`REQ-026` 与映射完整性。

判定标准以下方 Exit 为准；「能用」不算判据。
