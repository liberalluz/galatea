# SRS — galatea v0.2.0

简体中文 · [English](SRS.md)

## 范围

来源：`galatea-docs/product/definition/prd.md`——需求 `R1`–`R30`、可数产品规则
（PRD §5，B3）与全局体验约束（PRD §6，B10）；`REQ-031`–`REQ-035` 复述产品负责人
2026-11-21 确认的交互改版（PD 规格决策与骨架，即 galatea-docs 设计套件）。
本 SRS 把每条需求改写为可观察的验收判据，不复述 PRD。

- v0.1.0 已按 v0.1 措辞交付 `REQ-001`–`REQ-024`、`REQ-026`–`REQ-030`。
- v0.2.0 交互改版（产品裁定 2026-11-21）复述 `REQ-001`、`REQ-002`、`REQ-007`、
  `REQ-010`–`REQ-012`、`REQ-015`、`REQ-020`–`REQ-022`、`REQ-029` 并新增
  `REQ-031`–`REQ-035`；其余各行维持 v0.1.0 验收口径。
- `REQ-025`（iOS 功能确认，PRD R25）改期到 v0.2.x 补丁版（产品裁定 2026-11-21，
  方案 B），仅为追溯而列出，不在本切片内。
- 掌握度按音位计，KK / DJ / IPA 三体系共享（PRD C3）：指标分母为 48 个音位，
  不按体系乘 3。

## 产品规则（可数判据）

PRD §5（B3）定死的星级、复习与完成规则是 `REQ-021`–`REQ-023` 的验收基础：
星级初始 0，答对 +1 上限 3，答错 −1 下限 0；复习间隔按连续答对按
1/2/4/7/15 天递进，答错重置；完成 = 所选行内每个音位答题 ≥ 1 次；
掌握 = 3 星。星级三体系共享。

## 依赖与备选

自 PRD §7 带入；走备选路径只改受影响需求的验收措辞，不改需求本身：

| 输入 | 主路径 | 备选 | 影响 |
|---|---|---|---|
| 音位集与 KK/DJ/IPA 对照数据 | 从参照分册整理 | 按公开 KK/DJ/IPA 对照表自建并如实标注 | `REQ-001`、`REQ-012` |
| 原书授权 | 产品负责人确认 | 仅以 ISBN 作为音位集范围参照 | `REQ-001` 标注措辞 |
| 手写体字形与笔顺数据 | ED 制作 | 通用手写 IPA 字体 + 简化笔顺 | `REQ-008`、`REQ-009`、`REQ-013`、`REQ-018` |
| 口型图素材 | 自有绘制 / 授权素材 | 以固定占位槽位交付，数据结构预留图片路径 | `REQ-007` |
| 例词卡片配图 | 自有绘制 / 授权素材 | 每卡以固定占位图标交付，数据结构预留 image 字段 | `REQ-010`、`REQ-014` |
| 音频 | 端侧实时合成，免缓存 | 预生成音频随包分发 | `REQ-006`、`REQ-029` |
