### Changed
- The About page is rebuilt into the three groups the design spec fixes —
  app info, data source, usage and feedback — with the label in a 62 px
  column, a 1 px rule between groups and values aligned to one left edge.
- The two source rows carry the notation name in the label column (KK, and
  DJ / IPA), so the values read the booklet title with its ISBN and the
  international-notation note without a "KK source:" prefix.
- The feedback row is a dual entry: the repository button opens the project
  issue tracker, while the email button stays disabled until an address is
  configured.
- Spacing, the label column and the type steps now come from one token file
  rather than per-screen numbers.
