# B27 — Practice chain

## Added

- REQ-015 amended to the single-row ruling (2026-11-21): the chart's
  right-bottom floating button enters an in-page row-select state where
  exactly one row is selected at a time — default first row, tapping
  another row moves the selection — and confirm practices that row; the
  standalone range screen is abolished (Changed for the REQ-015 /
  TC-QUIZ-001 wording across the controlled set).
- The shared quiz page (`REQ-034`): one page hosts the quiz session for
  both the new-practice source (the selected row) and the review source
  (the due queue); only the item source differs.

## Changed

- `REQ-020` batch label: the top-right label now shows the selected
  row's coarse group (元音 / 辅音) or 复习 for a review session,
  replacing the phoneme-count denominator text.
- The chart gains the practice floating button, the 请选择 select bar
  and the green whole-row highlight; the fine group title map is gone.
